# Shuaib Ud Dowla Portfolio

Static personal portfolio for Shuaib Ud Dowla, a CSE undergradute and student developer focused on Android, Firebase, AI agents, and LLM workflows.

## Live Site

After deployment, the site is available at:

https://shuaibuddowla.github.io

## Project Structure

```text
.
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── main.js
│   └── images/
│       └── shuaib.png
└── README.md
```

## Features

- Responsive single-page portfolio
- Light and dark theme toggle
- Custom cursor color-drop animation
- Project, skills, achievements, education, and contact sections
- GitHub Pages-compatible static assets

## Deployment

This repository is intended to deploy through GitHub Pages from the `main` branch root folder.
